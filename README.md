# landpagesp
Super Cão Lanches — Landing Page

Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page para a Super Cão Lanches, uma lanchonete localizada em Palhoça, Santa Catarina.

A página foi criada com o objetivo de apresentar a lanchonete na internet, destacar seus lanches e facilitar o acesso dos clientes às informações de contato, localização e redes sociais.

Objetivo do projeto

Este projeto foi desenvolvido como parte da minha experiência de aprendizado, pois sou aluno da primeira fase do curso de Análise e Desenvolvimento de Sistemas (ADS) da Faculdade Municipal de Palhoça (FMP).

A ideia de criar essa landing page surgiu como uma oportunidade de colocar em prática os conhecimentos iniciais de desenvolvimento web, utilizando HTML e CSS para construir uma página simples, organizada e visualmente atrativa.

Além de praticar programação, busquei desenvolver um projeto com uma aplicação real, utilizando uma lanchonete local como referência.

Identidade visual e cores

A identidade visual foi pensada para transmitir uma aparência chamativa, moderna e relacionada ao ramo de alimentação.

As principais cores utilizadas foram:

Cor

Código hexadecimal

#ffffff

Melhorar a leitura dos textos e o contraste.

Complementar a aparência e facilitar a leitura de informações.

A combinação dessas cores busca deixar a página agradável, facilitar a visualização das informações e destacar os elementos mais importantes.

Tecnologias utilizadas

HTML5: estruturação do conteúdo da página.

CSS3: estilização, cores, organização dos elementos e responsividade.

Font Awesome: utilização de ícones para complementar a interface.

Git e GitHub: versionamento e armazenamento do projeto.

GitHub Pages: publicação da página na internet, caso habilitado no repositório.

Funcionalidades da página

Apresentação da Super Cão Lanches.

Exibição de imagens dos lanches.

Seção com informações da lanchonete.

Endereço e localização.

Informações de contato.

Links para WhatsApp e Instagram.

Layout adaptável a diferentes tamanhos de tela.
